# M3 环境探测与模式选择

## 完成项
- `probe_environment()`：npx/npm/git/node 路径与版本，缓存 10 分钟。
- `choose_mode()`：auto / npx / native；auto 只有在 **配了固定 CLI 版本** 时才委托（见 docs/decisions/remote-skills-mode.md）。
- 委托执行 `run_via_npx()`：白名单子命令与参数、不经 shell、临时 HOME/XDG、`DO_NOT_TRACK` + `SKILLS_TELEMETRY=0` + `CI=1`、新会话进程组、超时 kill、只"收获"不直接入库。
- 诊断 `doctor()`：DNS → TCP（区分直连/经代理）→ TLS/CA → 只读请求 → git 可达 → npx registry；每步耗时与错误码。

## 验证
- `tests/test_skill_sources_api.py::test_npx_mode_without_pin_prefers_native`、`…pinned_uses_npx`、`…rejects_unknown_flags` 通过。
- 真机取证（见 audit §2.3）：临时 HOME 不能阻止 CLI 写真实目录 → 默认 native。

## 已知问题
委托模式目前**没有强制沙箱**，因此只在用户显式设置 `mode=npx` 且配置固定版本时可用；界面会标注风险。
