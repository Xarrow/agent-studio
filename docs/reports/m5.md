# M5 网络策略

## 完成项
- `NetPolicy`：proxy_mode(system/env/manual/off)、bypass（域名后缀/通配/CIDR/端口；回环默认绕过可关）、ca_file、超时/重试、mirrors、allow_plaintext_hosts、registry 覆盖。
- 三条路径一致：httpx（client 级 proxy）、git（临时 GIT_CONFIG_GLOBAL + GIT_CONFIG_SYSTEM=/dev/null）、npx（npm_config_* 环境变量，不碰用户 .npmrc）。
- 重定向：自实现循环，最多 5 次，禁止 https→http 与非 http(s)，跨主机剥离 Authorization/PRIVATE-TOKEN。
- 镜像：模板 `{url}` / 完整 URL / 前缀三种写法；命中镜像记 `mirror-unverified`。
- 错误码：dns / connection_refused / timeout / certificate / handshake / proxy_auth(407) / rate_limited(429) / insecure_transport / redirect_downgrade / redirect_protocol / too_many_redirects。

## 验证（`tests/test_skill_source_net.py` 23 passed）
- 请求确实出现在夹具代理日志里（断言，不是推测）；NO_PROXY 命中时日志为空。
- 代理要求认证：错误凭据得到 407/网络错误码（夹具 Basic 认证）。
- 自签名 CA：未配置 CA 失败（certificate/network），配置后成功；不存在全局"跳过校验"开关。
- `git_env()`/`npm_env()`：用户 `.gitconfig`、`.npmrc` 前后字节一致。
- 明文传输默认拒绝（回环例外），https→http 降级拒绝。

## 已知限制
socks 代理未用夹具验证 → 界面不宣称支持；PAC/WPAD 不做（docs/decisions/pac.md）。
