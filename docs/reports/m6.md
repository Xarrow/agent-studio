# M6 检查更新与更新

## 完成项
- 两级判断：先比提交 ID（git ls-remote 或平台 API）；相同 → 直接"已最新"；不同 → 下载并比技能目录内容哈希，只有哈希也变才算"有更新"。
- 缓存与限频：`check` 结果写回 `skill.source.check`，默认 6 小时（设置项 `skills_check_interval_h`），`?force=true` 强制。
- 更新：`POST /api/skills/{id}/update` → 按 `source_id` 回到同一来源（无 source_id 时用记录的 address/url），重装经同一导入管线；固定 ref（SHA/tag）默认视为已固定。
- 单技能失败不影响其他技能；离线返回对应错误码不刷屏。

## 验证
- `test_check_updates_two_level_rule`：提交变但内容未变 → `has_update=false`；内容也变 → `true`；再更新后内容里出现新指令。
- 真机：`emilkowalski/skills` 安装后 `commit=0f2e23b3…`、`content_hash` 记录在 `skill.source`。
