# M2 原生获取与发现

## 完成项
- `fetch_via_git`：浅克隆（`--filter=blob:none`、可选 sparse-checkout），临时 `GIT_CONFIG_GLOBAL`，结束即删；记录 `rev-parse HEAD`。
- `fetch_via_archive`：平台归档模板下载 → 安全解压（拒绝穿越/绝对路径/链接/设备文件，条目与总大小上限）→ 提交 ID 从响应 URL 或平台 API 解析。
- `discover()`：子路径即技能 → 根即技能 → 约定目录 → 递归（深度 ≤4，命中不下钻，总量 ≤100）；frontmatter 校验；`internal` 默认隐藏；`skill_hash()` 稳定排序。
- `pick()`：按名字/路径选择，`*` 全选，同名多命中 → `ambiguous_skill`。
- 接入导入管线：`service.install()` 调既有 `_upsert_skill` + `_materialize`，`source` JSON 记录 source_id/commit/content_hash/mode/via/address。
