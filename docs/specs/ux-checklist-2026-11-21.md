## 0. 全局硬性规范

- [x] **G-1 自动保存**（助手配置页已落地）：去掉「保存」主按钮，停手 800ms 自动落库；顶栏只有一个状态位

- [ ] **G-4 就地完成**：改名、换模型、启停、试聊尽量在列表/当前页完成；必须跳页的，改完回到原位置。
- [x] **G-5 错误说人话**：中文原因 + 下一步动作；后端原文收进「详情」（`humanizeRunError`）。
- [x] **G-6 命名统一**：对话 / 运行记录 / 助手 / 记忆 / 知识中心 / 能力 / 远程节点 / LLM 配置 / 系统设置。
- [x] **G-7 危险操作**：删除前列出影响对象与数量；被引用时按钮置灰并写明原因，禁止假拦截。

## 1. P0 上线前必改

- [x] **UX-001 删除被引用 LLM 凭证真拦截**（M，/credentials）
  后端 409 兜底；⋯ 菜单置灰并点名「6 个助手在用，删不掉：A、B、C…」；未被引用时删除需输入配置名确认。
- [x] **UX-002 聊天时间戳**（S，/exec）

- [x] **UX-003 用户消息去重**（M，/exec）
  乐观回显与服务端消息按内容+轮次合并去重；重试目前仍是追加（原位替换未做，见下）。

## 4. LLM 配置 /credentials

- [x] **UX-015 新增配置「粘贴即用」（大部分）**（L）：
  名称自动生成（`deepseek-1`、冲突自动进位，不预填已存在的名字）；
  粘贴 Key 后 800ms 自动测一次连通性（同一个 key 只自动测一次）；
  测通后自动探测模型、就地铺出可筛选清单并回填第一个；
  空名 / 缺 Key / 重名分别给提示。
  未做：从 Key 前缀自动判断服务商（`sk-` 同时是 OpenAI / DeepSeek / 火山…，猜错更糟），仍由用户选服务商。
- [x] **UX-016 编辑态测试连接用已保存 Key**（S）：没选模型也能自检。
- [x] **UX-017 模型选择器统一组件**（M）：
  同一个 `ModelPicker` 现在用在四处（LLM 配置的默认模型、助手主模型、备用模型、新建向导）。
  搜索：大小写不敏感 + 多词 + 防抖；结果默认去重（`:batch`/`~` 别名），底部可「显示全部原始档（N）」；
  每行并排显示模型名与「¥输入/输出 · 每百万」（未定价的不显示，不编 0）；
  最近用过的 5 个置顶分组（localStorage）；点选即回填即关闭；无结果显示空状态 + 「清空」。
  LLM 配置页原来的 462 个 chip 平铺已删除，换成这个选择器（探测按钮也并进了选择器）。
  未做：上下文长度（服务商没给，不编数据）。
- [x] **UX-018 定价字段带单位**（S）：列头「输入¥/百万」「输出¥/百万」，币种去重。
