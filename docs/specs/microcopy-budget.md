# 辅助说明预算（microcopy budget）

页面用**布局**解释自己，不用句子解释自己。这份文件是判定口径，也是门禁脚本的规则来源
（`web/scripts/audit-microcopy.mjs`，`npm run build` 会跑 `--check`）。

## 三类判定

**留（三类，且要短）**

1. 会做错事的：不可逆、删数据、凭据/口令、费用额度、权限范围。
2. 失败与状态：报错原因、下一步动作、未生效/需重启、空态（一句 + 一个动作）。
3. 术语的最短一句：同一术语全站只解释一次，不逐处重复。

**删（默认处理方式）**

- 复述交互：「点击 X 就会 Y」「勾选 = 挂给这个助手」「点右边试运行就在这里出表单」。
- 实现内幕：「和助手页是同一份数据」「经导入管线原子安装」「看提交再比内容哈希」。
- 架构科普：「一个文件就是整个数据库，适合单机」「缺了一键装到平台目录」。
- 跨页引用：「和 X 页一样」「另一个入口在 Y」。

**改（不是删，是换成控件）**

- 字段规则 → 占位示例 + 单位后缀（`60` + `秒`），不写「默认 60 秒」。
- 枚举 → 选择器；能选就不让填。
- 顺序/步骤 → 编号标题或步骤条（①标签 ②技能 ③试打）。
- 约束（必须先测通才能切）→ 按钮禁用态 + 原因就近一行，不用灰字说明书。

## 禁止的偷懒

- 不加 hover tooltip 兜底（触屏等于不存在）。
- 不把说明塞进 `ⓘ` 图标——那是换个地方放噪音。
- 不为了少字而用更难懂的词。

## 门禁

`scripts/microcopy-allow.json` 冻结当前存量（62 条），新增「删/改」类文案会让构建失败：

```
npm run microcopy          # 看清单
npm run microcopy -- --check
node scripts/audit-microcopy.mjs --write-allow   # 清理后重新冻结
```

清一条就从 allow 里去掉一条——只减不增。
